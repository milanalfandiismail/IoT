# Kontrol LED ESP32 via Flask — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Flask API + dashboard login yang mengontrol satu LED ESP32 lewat HTTP polling 1 detik dengan bearer token.

**Architecture:** Satu file `app.py` berisi factory `create_app()`, state LED di memori, dua jenis auth (session cookie untuk browser, bearer token untuk API). ESP32 sebagai client yang poll `GET /api/device/state` tiap detik.

**Tech Stack:** Python 3.14, Flask 3, pytest, Arduino C++ (ESP32 core), `HTTPClient`.

**Spec:** `docs/superpowers/specs/2026-11-10-iot-led-design.md`

## Global Constraints

- Token dan kredensial **hanya** dibaca dari environment; tidak ada nilai rahasia di kode atau repo.
- `POST /api/led` menerima `{"on": <boolean>}` — boolean ketat; `1`, `"true"`, `null` ditolak 400.
- `API_TOKEN` dan `DEVICE_TOKEN` tidak boleh saling berlaku di endpoint yang salah.
- Interval polling firmware 1 detik, `http.setTimeout(2000)`, `http.end()` selalu dipanggil.
- Pin LED: GPIO2. Baud serial: 115200.
- Nama file, path, dan signature di plan ini sudah final; jangan diganti di tengah jalan.
- Bahasa komentar dan README: Indonesia. Nama variabel/fungsi: Inggris.

## Review Focus

- Body dengan `Content-Type` bukan JSON atau body kosong → 400, bukan 500.
- `{"on": 1}` (integer) → 400, bukan diterima.
- Scheme `bearer` huruf kecil → diterima.
- `/api/device/state` dipanggil dengan `API_TOKEN` → 401.
- Request tanpa header `Authorization` ke endpoint API → 401, bukan error 500.

```python
STATE = {"on": False}

def bearer_ok(expected: str) -> bool:
    scheme, _, token = request.headers.get("Authorization", "").partition(" ")
    return scheme.lower() == "bearer" and token.strip() == expected

@app.post("/api/led")          # session valid ATAU bearer_ok(API_TOKEN)
@app.get("/api/device/state")  # hanya bearer_ok(DEVICE_TOKEN)
```

`POST /api/led`: `request.get_json(silent=True)`, tolak bila bukan `dict` atau `isinstance(body.get("on"), bool)` False → `(jsonify(error=...), 400)`. Sukses → set `STATE["on"]`, return `jsonify(STATE)`.

Gunakan `hmac.compare_digest` di dalam `bearer_ok` untuk perbandingan token.

### Task 4: Firmware ESP32 polling

**Files:**
- Create: `esp32/led_poll/led_poll.ino`
- Create: `esp32/README.md`

**Interfaces:**
- Consumes: `GET /api/device/state` + `DEVICE_TOKEN` dari Task 2
- Produces: firmware yang menyalakan GPIO2 sesuai `{"on": bool}`

- [ ] **Step 1: Tulis sketch**

```cpp
#include <WiFi.h>
#include <HTTPClient.h>

const char* SSID     = "SSID_WIFI";
const char* PASSWORD = "PASSWORD_WIFI";
const char* URL      = "http://192.168.1.10:5000/api/device/state";
const char* TOKEN    = "ganti-device-token";
const int   LED_PIN  = 2;

String authHeader;

void setup() {
  Serial.begin(115200);
  pinMode(LED_PIN, OUTPUT);
  digitalWrite(LED_PIN, LOW);
  authHeader = String("Bearer ") + TOKEN;
  WiFi.begin(SSID, PASSWORD);
  while (WiFi.status() != WL_CONNECTED) {
    delay(300);
    Serial.print(".");
  }
  Serial.println("\nWiFi tersambung");
}

void loop() {
  static unsigned long lastPoll = 0;
  if (millis() - lastPoll < 1000) return;
  lastPoll = millis();

  HTTPClient http;
  http.setTimeout(2000);
  http.begin(URL);
  http.addHeader("Authorization", authHeader);
  int code = http.GET();
  if (code == 200) {
    String body = http.getString();
    digitalWrite(LED_PIN, body.indexOf("true") >= 0 ? HIGH : LOW);
  } else {
    Serial.printf("poll gagal: %d\n", code);
  }
  http.end();
}
```
